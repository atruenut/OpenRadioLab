# Roadmap

OpenRadio Lab is organised around six areas. Done means "works and has been used"; see README for what is hardware-verified.

| Area | Purpose | State |
|---|---|---|
| **Radio Explorer** | Spectrum, waterfall, click-to-measure, listening, FM scan, stereo | done (v0.8) |
| **Learning Center** | Lessons and dictionary for beginners | 10 lessons + dictionary; needs more, and translations |
| **Signal Laboratory** | Measure signals over time | level-over-time, duty cycle, bursts, CSV; next: spectrum snapshots, comparison between captures |
| **Experiment Journal** | Notes tied to exact settings | done (plain text + Markdown export); next: attach screenshots/audio |
| **Frequency Atlas** | What is allocated where | simplified table only; **real Canadian (ISED) data wanted** |
| **Antenna Workshop** | Build and understand antennas | lesson 4 only; next: interactive length calculator, build guides |

Also planned: SSB/CW, HF direct sampling, audio (WAV) export of what you hear, more SDR backends, a signed installer, and HiDPI polish.
